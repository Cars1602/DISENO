# 🍽️ Bolivian Food

Aplicación web para restaurante de comida boliviana: menú digital con pedidos en línea, reservas y un panel de gestión para el equipo del restaurante. Diseñada con enfoque *responsive* (escritorio y móvil).

---

## 📋 Características

- **Menú digital** con categorías: Todos, Entrada, Menú y Postre.
- **Menú del día** destacado en la parte superior.
- **Carrito de pedido** con subtotal, propina y total.
- **Botón de pago** para finalizar la orden.
- **Reservas** de mesa.
- **Sección "Acerca de"** con la descripción del restaurante.
- **Panel administrativo** con resumen de reservas, ingresos, pedidos y clientes.
- **Diseño adaptable** a computadora y celular.

![Panel de gestión](/administrativo.png)

Panel de gestión con:
- Tarjetas de métricas: reservas, ingresos, pedidos y clientes.
- Tabla de reservas recientes con estado (confirmada / pendiente).
- Gráfico de ventas semanales.
- Menú lateral: Resumen, Reservas, Ventas y Acciones.
